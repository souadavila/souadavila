# 🛡️ TryHaOckMe - Offensive Security Intro

Repositório dedicado ao registro dos meus estudos e conceitos práticos aprendidos na sala de introdução à Segurança Ofensiva do *TryHackMe*.

---

## 📌 Visão Geral do Desafio
O laboratório simula uma aplicação bancária vulnerável (*FakeBank*). O objetivo principal foi entender como um atacante pode explorar falhas de lógica em aplicações web e como os desenvolvedores devem proteger essas funcionalidades.

---

## 🧠 Principais Aprendizados

* *Exploração de Parâmetros Web:* Compreensão de como o mapeamento de diretórios com a ferramenta *dirb*, e a manipulação de requisições pode alterar dados no servidor (como o saldo de uma conta bancária).
* *Controle de Acesso e Autenticação:* A importância de restringir o acesso a páginas críticas e validar a sessão do usuário no lado do servidor (Server-Side-Validation).
* *Mitigação de Vulnerabilidades:* Toda informação enviada pelo navegador deve ser validada e higienizada no servidor.

---

## 🛠️ Tecnologias e Ferramentas
* *Plataforma:* TryHackMe
* *Conceitos:* Segurança de Aplicações Web, Segurança Ofensiva, Manipulação de parâmetros, Mapeamento de Diretórios
* *Ferramentas:* Dirb
