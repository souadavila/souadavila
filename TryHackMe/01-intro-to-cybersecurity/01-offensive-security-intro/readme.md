# 🛡️ TryHackMe - Offensive Security Intro

Repositório dedicado ao registro dos meus estudos e conceitos práticos aprendidos na sala de introdução à Segurança Ofensiva do *TryHackMe*.

---

## 📌 Visão Geral do Desafio
O laboratório simula uma aplicação bancária vulnerável (*FakeBank*). O objetivo principal foi entender como um atacante pode explorar falhas de lógica em aplicações web e como os desenvolvedores devem proteger essas funcionalidades.

---

## 🧠 Principais Aprendizados

* *Exploração de Parâmetros Web:* Compreensão de como a manipulação de requisições pode alterar dados no servidor (como o saldo de uma conta bancária).
* *Controle de Acesso e Autenticação:* A importância de restringir o acesso a páginas críticas e validar a sessão do usuário.
* *Mitigação de Vulnerabilidades:* A principal medida corretiva para proteger rotas sensíveis é implementar *autenticação obrigatória* (Require authentication).

---

## 🛠️ Tecnologias e Ferramentas
* *Plataforma:* TryHackMe
* *Conceitos:* Web Application Security, Offensive Security, Parameter Tampering
